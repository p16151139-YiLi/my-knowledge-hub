AI Agent 與 Tool Use

理解 AI Agent 如何透過外部工具取得資訊、執行操作，再將結果整合成回應。

核心概念

AI Agent 是能根據目標進行判斷並採取行動的系統。Tool Use（工具使用）是常見方法之一，讓模型在需要時呼叫搜尋、計算或其他外部工具，而不是只依賴模型內部知識回答。

基本工作流程

  1. 接收使用者任務。
  2. 判斷是否需要外部工具。
  3. 選擇工具並整理呼叫參數。
  4. 取得工具回傳結果。
  5. 整合結果並產生回應。

設計注意事項

工具應有清楚的用途、輸入格式與輸出格式。系統也需要處理工具失敗、回傳資料不完整、重複呼叫及使用者權限等問題。

應用情境

例如學習助教可以先判斷問題是否需要最新資料；若需要，便呼叫網路搜尋工具，再根據搜尋結果整理說明並附上來源。若不需要外部資料，則直接使用模型知識回答。

工具回傳的文字應視為資料，而不是可信任的系統指令；Agent 必須遵守預先定義的權限與安全規則。
